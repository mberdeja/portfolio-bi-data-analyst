# Dashboard de oportunidad comercial en Power BI

> 🚧 Case study en construcción.

## Contexto / problema de negocio

Un equipo comercial necesitaba identificar, dentro de su propia base de clientes, cuánto volumen de negocio mueven fuera de la relación comercial existente (la "oportunidad" desaprovechada), y priorizar dónde enfocar el esfuerzo comercial.

## Rol y alcance

Rediseño integral de un dashboard de Power BI existente: mejora de la calidad visual y suma de nuevas capas analíticas.

## Fuentes de datos y stack técnico

- Power BI (DAX, Power Query, bookmarks, drill-through)
- Cruce de datos internos de ventas/transacciones con datos externos de mercado, unidos por identificador fiscal del cliente

## Enfoque / metodología

- Sistema de color semántico: cada color tiene un rol fijo (métricas propias, contexto de mercado, señales de riesgo), no solo estético
- Colapso de elementos visuales redundantes (medidores + tarjetas → un solo gráfico de bala) para ganar claridad sin perder información
- Matriz de riesgo de concentración de clientes: un gráfico de burbujas que cruza oportunidad disponible vs. participación ya capturada, con cuadrantes que priorizan la acción comercial (prioridades, cuentas ancla a proteger, cuentas a monitorear, cuentas saturadas)
- Enfoque iterativo: validar un piloto en una sola vista antes de escalar el rediseño a todo el dashboard

## Resultado / impacto

El dashboard pasó de mostrar indicadores sueltos a contar una historia priorizada y accionable para el equipo comercial.
